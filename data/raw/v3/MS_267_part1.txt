# Kế hoạch Chuyển đổi Hạ tầng Điện toán đám mây (Cloud Migration)

## I. Nội dung chính

### 1. Mục tiêu cuộc họp
- Thảo luận và thống nhất chiến lược chuyển đổi hạ tầng từ server vật lý sang nền tảng Cloud.

### 2. Các vấn đề đã thảo luận
- Lựa chọn nhà cung cấp: Cân nhắc giữa hệ sinh thái của AWS và tính tương thích của Azure với hệ thống hiện tại.
- Bảo mật và Pháp lý: Tuân thủ quy định về chủ quyền dữ liệu của Ngân hàng Nhà nước; đề xuất mô hình Hybrid Cloud để bảo vệ dữ liệu nhạy cảm.

### 3. Kết luận và quyết định
- Thống nhất triển khai theo mô hình Hybrid Cloud (ứng dụng trên Cloud quốc tế, dữ liệu core đặt tại Data Center trong nước).
- Phê duyệt lộ trình chuyển đổi 3 giai đoạn: Thử nghiệm -> Ứng dụng phụ trợ -> Hệ thống lõi (Core-banking).
